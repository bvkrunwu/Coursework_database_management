# 🎯 Project Vacancy Hunter: Сбор и анализ данных о вакансиях с hh.ru

---

## 🖥️ Описание проекта

Проект *Vacancy Hunter* разработан для автоматизации процесса сбора и анализа данных о вакансиях с популярного российского портала трудоустройства — hh.ru. Система позволяет собирать подробную информацию о работодателях и актуальных вакансиях, хранить её в базе данных PostgreSQL и осуществлять дальнейший анализ.

Цель проекта — упростить мониторинг рынка труда, предоставление актуальной статистики по востребованным профессиям и помощь в принятии карьерных решений.

---

## ⚙️ Технические подробности

Проект реализован на языке программирования Python и использует следующие технологии и библиотеки:

- **Python 3.x**
- **PostgreSQL** — СУБД для хранения данных
- **Psycopg2** — драйвер для работы с PostgreSQL
- **Requests** — библиотека для взаимодействия с API hh.ru
- **Dotenv** — работа с переменными окружения
- **Typing** — поддержка аннотаций типов

---

## 📦 Компоненты проекта

Проект состоит из четырёх основных модулей:

1. **api_hh.py** — модуль для взаимодействия с API hh.ru, позволяющий извлекать данные о работодателях и их вакансиях.
2. **database.py** — модуль для создания и заполнения базы данных PostgreSQL собранными данными.
3. **db_manager.py** — реализация класса `DBManager` для эффективного управления данными в базе.
4. **main.py** — точка входа в приложение, обеспечивающая удобное взаимодействие с системой через командную строку.

## 🛠️ Установка и настройка

Для запуска проекта следуйте следующим простым шагам:

### Шаг 1: Установите необходимые пакеты
Установите Python версии 3.8+ и установите нужные библиотеки командой:

```bash
pip install psycopg2 requests python-dotenv
```

### Шаг 2: Настройте подключение к PostgreSQL
Создайте файл `.env` и добавьте туда ваши учетные данные для подключения к PostgreSQL:

```
DB_PASSWORD=your_password_here
```

Также создайте файл `database.ini` с параметрами подключения к базе данных:

```
[postgresql]
host=localhost
database=job_vacancy
user=postgres
password=your_password_here
port=5432
```

### Шаг 3: Подготовьте базу данных
Выполните скрипт создания базы данных и таблиц:

```bash
python database.py
```

---

## 🚀 Запуск проекта

Просто запустите основное приложение следующей командой:

```bash
python main.py
```

После запуска откроется интерактивное меню, позволяющее выполнять различные операции с данными.

## 🔍 Примеры использования

После запуска приложения вы увидите следующее меню:

```
Добро пожаловать в систему управления вакансиями!
Выберите действие:
1. Получить список компаний и количество вакансий у каждой
2. Просмотреть все вакансии с указанием компании, названия, зарплаты и ссылки
3. Узнать среднюю зарплату по всем вакансиям
4. Показать вакансии с зарплатой выше средней
5. Найти вакансии по ключевому слову (например, 'Аналитик')
6. Завершить работу
```

Примеры действий:

- Выберите пункт 1, чтобы просмотреть список компаний и количество открытых вакансий.
- Выберите пункт 3, чтобы быстро оценить средний уровень заработной платы по рынку.
- Используйте пункт 5 для поиска вакансий по интересующим вас ключевым словам.
